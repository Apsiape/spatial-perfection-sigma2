\section{Reproducibility}\label{sec:repro}
The accompanying \texttt{verification/} directory contains the tree-and-clock checker, the primitive-phase checker, their execution logs, and the independent compiler replication artifacts available at packaging time. Its README states commands, dependencies, provenance and limitations. \texttt{SHA256SUMS} identifies every bundled file apart from itself. Public paths are relative. The three compiler entry points accept
\texttt{--output-dir DIR}, defaulting to \texttt{compiler/generated/};
they refuse to overwrite the shipped compiler directory or toolkit.
Windows memory telemetry is guarded on other platforms. Fresh revision
logs and the check summary are in \texttt{logs/revision-checks/}; generated
output directories and Python bytecode caches are excluded from the
shipped-file manifest.

The numerical tree checker constructs the truncated Fock model, Weyl pair, coordinate increments, clock, counter and exact-return candidate. Its pulse-driven cellular automaton is a small front-and-mark model. It is not an implementation of every Turing-machine decoder used by the reduction. The checker tests the creation and range identities, modular scaling, endpoint recurrences, clock and reader equations, tableau propagation, centralizer commutators and top-depth defects. The four diagonal isometry equations fail exactly at the top depth, as predicted by \eqref{eq:fourdefects}; all other reported residuals are at floating-point precision. The analytical mass is \eqref{eq:topmass}.

The primitive-phase checker tests the existence of a good primitive phase for every prime below $4000$ and tests the chord lower bound only for primes below $400$. Its trigonometric evaluations use floating point. Lemma~\ref{lem:goodphase} is the proof for all primes. The independent exact tree suite checks ten models, depths $0$ through $4$ and clock orders $2,3$, with $2000$ exact checks in total. A separate minimal compiler instance has four bridges and one modular isometry, but no transported endpoint labels. It has $748$ rational rows and $27\,991$ questions per party. Its independent structural audit checks $77\,750$ serialized bindings, $11\,652$ column-graph rules, all $748$ row expansions, $333$ scalar pair contexts and $2472$ old forbidden events. It does not instantiate the full ten-label computation compiler. This minimal instance is the only compiled game: the full reduction game $G_e$ of Theorem~\ref{thm:reduction} was not compiled. These exact replication calculations and their relative-path packaging are separately identified in the ancillary README. No proof-assistant certification is claimed.

The paper is built with \texttt{python build.py} from \texttt{paper/}. This runs \texttt{pdflatex}, BibTeX and the required repeat passes, and fails if the final log contains a warning, an undefined reference, or an overfull or underfull box. The plain-text abstract is \texttt{abstract.txt}.
